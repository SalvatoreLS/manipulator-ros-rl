# Results

> **Status: runs not yet executed.** The figures and tables below are generated by
> `scripts/plot_results.py` from the TensorBoard logs of the sweep in
> `scripts/run_experiments.sh`. Until that sweep has been run on this machine, no numbers

## Setup

| | |
|---|---|
| Robot | Franka FR3, 7-DOF, simulated in Gazebo (headless, `-s -r empty.sdf`) |
| Controller | `forward_position_controller` via `ros2_control` |
| Task | reach a target sampled uniformly in the reachable workspace |
| Episodes / run | 150 |
| Max steps / episode | 150 |
| Seeds | 0, 1, 2 |
| Throughput | ~2.9 environment steps/s (dominated by the controller round-trip, not compute) |
| Wall clock | ≈ 2.1 h per run; ≈ 4–5 h for the whole 6-run sweep at `--parallel 3` |
| Agent | SAC from scratch — 2×256 MLP, lr 3e-4, batch 256, buffer 50k, 6 gradient steps per env step, automatic entropy tuning |
| Baseline | Stable-Baselines3 `SAC`, identical hyperparameters and step budget |
| Hardware | 12-core CPU, 30 GB RAM, NVIDIA Quadro T2000 (4 GB) |

Reproduce with:

```bash
# inside the container: docker exec -it franka_ros2_rl bash
./scripts/run_experiments.sh          # 3 seeds x 2 agents, 3 concurrent runs
python3 scripts/plot_results.py --runs-dir output/runs --out-dir docs/figures
```

Concurrent runs are isolated by `ROS_DOMAIN_ID` and `GZ_PARTITION`, so the three
simulations never share a topic graph.

## Cross-check against Stable-Baselines3

The SB3 run exists to validate the from-scratch implementation, not to compete with it:
same environment, same hyperparameters, same budget. Curves that track each other are
evidence the hand-written SAC — twin critics, tanh-squashed Gaussian with the log-prob
correction, Polyak target updates, automatic temperature tuning — is correct. A systematic
gap would be a bug worth chasing, and would be reported here either way.

## Limitations

Stated plainly, because they bound what these numbers mean:

- **Position-only reward.** No orientation target, no collision penalty, no effort or
  action-rate regularisation. The policy is free to reach a point in any wrist
  configuration, including ones that would be unusable for grasping.
- **No obstacles.** The scene is empty; nothing tests collision avoidance.
- **Single, non-vectorised environment.** Wall-clock time is dominated by the ROS 2
  command/feedback round-trip (~345 ms/step measured), not by compute — shortening the
  settle window does not help. Vectorised environments would be the obvious speed-up and
  are not implemented; the sweep parallelises across *runs* instead.
- **No domain randomisation and no sim-to-real transfer.** Everything reported here is in
  simulation. The interface supports real hardware (the EE position falls back to the
  Franka state broadcaster automatically), but nothing has been run on a physical arm.
- **Short runs.** 150 episodes × 150 steps (~22.5k environment steps) is a modest budget,
  chosen to fit the available machine at ~2.9 steps/s; the curves show learning, not
  converged asymptotic performance.
- **Three seeds.** Enough to show the spread, not enough for a statistical claim about
  small differences between the two agents.
